Компактная библиотека C++20 для сравнения объектов, отслеживания полей и восстановления состояния. Один заголовок. Все важные изменения.

Полный пример↗
example.cpp 
// Поля Item зарегистрированы в schema<Item>.
const std::vector<Item> before{
    {1, 10}, {2, 20}, {3, 30}
};
const std::vector<Item> after{
    {2, 20}, {3, 30}, {1, 12}
};

auto changes = vardiff::deep_diff(
    before, after,
    vardiff::key(&Item::id)
);

Сопоставление по id. Всего одно перемещение.

struct Player { int hp = 100; };
Player player;

auto watcher = vardiff::track(
    player,
    vardiff::field("hp", &Player::hp)
);

player.hp = 75;
auto changes = watcher.diff();

Объект остаётся вашим. Проверяйте изменения, когда нужно.

Точные пути. Исходные типы. Ясная картина до и после.

Контракты API↗
01

Вложенность — естественно

Обход структур, векторов, словарей, массивов и optional. Точный путь ведёт к самому изменённому полю.

02

Сопоставление по смыслу

Задайте свой ключ. Находите перемещения, добавления и удаления с предсказуемой обработкой дубликатов.

03

Возможность вернуться

Сохраняйте ограниченную историю снимков. Восстанавливайте состояние через undo, redo и rollback.

Можно подключать

Один заголовок.Сразу в ваш проект.

Скопируйте заголовок в каталог include или добавьте VarDiff в CMake-проект и подключите его цель.
