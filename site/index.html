Full example↗
example.cpp 
// Item fields are registered with schema<Item>.
const std::vector<Item> before{
    {1, 10}, {2, 20}, {3, 30}
};
const std::vector<Item> after{
    {2, 20}, {3, 30}, {1, 12}
};

auto changes = vardiff::deep_diff(
    before, after,
    vardiff::key(&Item::id)
);

struct Player { int hp = 100; };
Player player;

auto watcher = vardiff::track(
    player,
    vardiff::field("hp", &Player::hp)
);

player.hp = 75;
auto changes = watcher.diff();

Read the contracts↗
01

Nested by design

Walk registered structures, vectors, maps, arrays and optionals. Follow a change all the way to its leaf.

02

Identity over position

Match elements by your own key. Detect moves, additions and removals, with predictable handling of duplicate keys.

03

A way back

Keep bounded snapshot history. Restore a saved state with undo, redo and rollback.
