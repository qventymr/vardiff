# Производительность

## Реализованные оптимизации

- changed() останавливается на первом отличии и не создаёт change/value,
  не копирует наблюдаемые значения. Без ignore() он также не строит пути.
- poll() без отличий возвращается после проверки, не захватывая новый снимок
  и не добавляя историю.
- diff() пропускает равные вложенные ветви до создания строк дочерних путей.
  Равные элементы контейнера без ignore() также не требуют строк индексов.
- При захвате снимка каждый выбранный верхний уровень копируется ровно один раз
  непосредственно в tuple. Нет промежуточного tuple с последующим перемещением.
- История ограничена; удаление старого снимка не сдвигает значения остальных.
  Неизменяемые состояния принадлежат истории; ветвление и копирование наблюдателя
  используют внутренние ссылки на эти состояния вместо повторного копирования.
- При обходе callbacks не копируются `std::function`, а новые регистрации
  откладываются до следующего poll(). Состояние mutable-callback сохраняется.
- Описания вложенных зарегистрированных типов кешируются при первом обращении.

Начальная инициализация схемы может выделять память. Компаратор, пользовательское
копирование и оператор вывода сами могут выделять память или выполнять дорогую
работу. Библиотека не задаёт для них ограничений.

Тесты проверяют отсутствие копирования значений при changed(), пустом diff()
и пустом poll(), короткое замыкание changed() и ровно одну копию поля при
создании снимка.

## Сложность и выбор API

Для плоских полей changed() посещает не больше числа выбранных полей.
Рекурсивное сравнение в худшем случае посещает все зарегистрированные листья
и элементы контейнеров. Проверка длинного равного vector требует линейного
просмотра; обнаружение отличия размера в changed() может завершиться сразу.

diff() должен сформировать все изменения и скопировать их значения.
Проверка равенства ветвей может добавлять повторные сравнения: выигрыш
заключается в отсутствии создания путей для равных поддеревьев.
При значительной глубине и большом числе изменений этот выигрыш зависит от данных.

poll() с изменениями дополнительно копирует все выбранные поля в согласованное
состояние до callbacks. Снимок всего vector необходим и при изменении только
одного элемента. Ограничивайте выбранные поля и размер истории, если значения
велики. Оценка памяти истории — сумма размеров сохранённых значений с обычными
правилами копирования их типов; лимит ограничивает число снимков, а не байты.

history() намеренно копирует историю для безопасного независимого результата.
history_size(), history_position(), can_undo() и can_redo() обходятся без
копирования. Используйте их для проверки состояния интерфейса.

## Запуск benchmark

Никаких сторонних библиотек для benchmark не нужно:

```sh
cmake -S . -B build-bench -DCMAKE_BUILD_TYPE=Release -DVARDIFF_BUILD_BENCHMARKS=ON
cmake --build build-bench --target vardiff_benchmark
./build-bench/vardiff_benchmark 10000
```

Исполняемый файл измеряет changed(), diff() и poll() на объекте с числовым полем
и `vector<int>` из 4096 элементов. Есть режимы без отличий, с отличием первого поля,
с изменением последнего элемента и с записью снимков через poll().
Выводятся ns/op и контрольная сумма результатов. Можно менять число повторений.

Это небольшой диагностический benchmark, а не универсальный рейтинг.
Результаты зависят от компилятора, оптимизации, процессора и нагрузки.
В CI нет порогов времени: функциональные и счётные проверки детерминированы.

## Контрольное измерение оптимизации

Один локальный запуск: GCC 15.2, C++20, Release (-O3, NDEBUG), 10 000 повторений,
`vector<int>` из 4096 элементов. Сравнивались версии 0.2 до и после добавления
пропуска равных ветвей; это не сравнение с первоначальным MVP.

| Нагрузка | До, ns/op | После, ns/op |
| --- | ---: | ---: |
| diff(), без изменений | 115655.1 | 1071.9 |
| diff(), изменён последний элемент | 114901.3 | 7264.2 |
| poll(), изменённое числовое поле | 109009.3 | 1535.3 |

Контрольные суммы совпали. Основной эффект — отсутствие построения путей для
тысяч равных элементов. Эти цифры иллюстрируют конкретную нагрузку и не задают
гарантий для других объектов или оборудования.
