# vardiff 0.2.0

First public release candidate of vardiff: a header-only C++20 library for
tracking changes to selected object fields, with no external runtime dependencies.

- Track explicit fields and inspect owned before/after values.
- Poll for deferred callbacks, ignore paths, and supply custom equality predicates.
- Keep bounded snapshot history and restore states with rollback, undo, and redo.
- Compare independent objects and registered nested structures, including value trees.
- Inspect element changes in vector, optional, and array.
- Integrate through add_subdirectory or an installed find_package(vardiff) package.

The original Player example remains supported. Documentation and examples are
available in English and Russian. The project is licensed under Apache-2.0.

## Behavioral notes

Callbacks run only during poll(). Automatic snapshots are enabled by default
and the history limit is 64, including the current snapshot. The observed object
must outlive its watcher and remain at the same address. Restoration requires
assignable fields. Floating-point comparison uses operator== unless overridden.
